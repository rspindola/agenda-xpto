# Language Standards - Agenda XPTO

## Cursor/Agent Responses
- **MUST** always respond to the user in **Brazilian Portuguese (pt-BR)**.
- Use pt-BR for explanations, suggestions, and clarifications.
- **NEVER** respond in English, even if the user writes in English.

## Code Language
- **MUST** write all variable names, function names, class names, and type names in English.
- **MUST** write all comments and documentation in English.
- **MUST** write all error messages and log messages in English.
- **MUST** write Git commit messages in English (Conventional Commits).
- **NEVER** use Portuguese words in code identifiers.
