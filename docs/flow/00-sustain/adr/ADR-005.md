# ADR-005 — Better Auth para autenticação
**Data:** Abril 2026 | **Status:** Aceito

## Contexto
Precisamos de autenticação com sessões, refresh tokens, e possivelmente OAuth (Google) no futuro. Queremos evitar dependência de serviço externo pago.

## Decisão
Usar **Better Auth**.

## Consequências
✓ Self-hosted — sem custo por usuário  
✓ Suporte a sessões, JWT, OAuth, 2FA  
✓ TypeScript nativo com tipagem completa  
✓ Integração direta com Prisma  
✓ Ativo e mantido (2024+)  
✗ Menos maduro que NextAuth / Auth.js  
✗ Documentação ainda crescendo  

## Alternativas consideradas
- **Auth.js (NextAuth)**: maduro mas acoplado ao ecossistema Next.js
- **Clerk**: excelente DX mas custo por usuário (inviável para SaaS early-stage)
- **Supabase Auth**: boa opção mas criaria dependência de plataforma externa
- **JWT manual**: flexível mas requer implementar refresh token, revogação, etc.
