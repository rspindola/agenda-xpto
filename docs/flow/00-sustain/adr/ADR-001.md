# ADR-001 — Monorepo com Turborepo e pnpm
**Data:** Abril 2026 | **Status:** Aceito

## Contexto
O projeto tem frontend (React), backend (Fastify) e pacotes compartilhados (tipos, validações Zod). Precisamos de uma forma de gerenciar tudo no mesmo repositório sem duplicar código.

## Decisão
Usar **Turborepo** como orquestrador de tasks com **pnpm workspaces** para gerenciar dependências.

## Consequências
✓ Build cache inteligente — só rebuida o que mudou  
✓ Tasks paralelas (build web + api ao mesmo tempo)  
✓ Compartilhamento de `packages/types` e `packages/validations` sem publicar no npm  
✓ Um único `git clone` para rodar tudo  
✗ Curva inicial de configuração do `turbo.json`  
✗ pnpm é menos familiar que npm para alguns colaboradores futuros  

## Alternativas consideradas
- **Nx**: mais poderoso, mas complexidade desnecessária para solo dev
- **Repositórios separados**: mais simples inicialmente, mas dificulta compartilhamento de tipos e sincronização de versões
