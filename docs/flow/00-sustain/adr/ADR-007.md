# ADR-007 — Caddy como reverse proxy
**Data:** Abril 2026 | **Status:** Aceito

## Contexto
Em produção na VPS, precisamos de um reverse proxy para rotear requests, terminar TLS (HTTPS) e servir o frontend estático.

## Decisão
Usar **Caddy v2**.

## Consequências
✓ HTTPS automático via Let's Encrypt — zero configuração manual de certificados  
✓ Caddyfile simples — dezenas de linhas vs centenas no Nginx  
✓ HTTP/2 e HTTP/3 por padrão  
✓ Adequado para solo dev em VPS  
✗ Menor adoção que Nginx — menos exemplos na comunidade  
✗ Algumas configurações avançadas menos documentadas  

## Exemplo de Caddyfile
```
agendaia.com {
  reverse_proxy /api/* localhost:3001
  root * /var/www/agendaia
  file_server
}
```

## Alternativas consideradas
- **Nginx**: padrão da indústria, mais exemplos, mas configuração de TLS manual e verbose
- **Traefik**: ótimo com Docker Swarm/K8s, complexidade desnecessária para VPS simples
