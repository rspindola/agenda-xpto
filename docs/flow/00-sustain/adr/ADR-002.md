# ADR-002 — Fastify em vez de Express
**Data:** Abril 2026 | **Status:** Aceito

## Contexto
Precisamos de um framework HTTP para o backend Node.js. Express é o mais conhecido, mas existem alternativas mais modernas.

## Decisão
Usar **Fastify v5**.

## Consequências
✓ ~2x mais performático que Express em benchmarks reais  
✓ Schema validation nativa com JSON Schema / Zod plugin  
✓ TypeScript como cidadão de primeira classe  
✓ Plugin system organizado (cors, jwt, swagger em plugins separados)  
✗ Ecossistema menor que Express (menos middlewares prontos)  
✗ Alguns padrões diferentes de Express que podem gerar confusão inicial  

## Alternativas consideradas
- **Express**: familiar, mas sem TypeScript nativo e performance inferior
- **Hono**: leve e rápido, mas ecossistema ainda pequeno para produção SaaS
