# ADR-003 — Prisma como ORM
**Data:** Abril 2026 | **Status:** Aceito

## Contexto
Precisamos de uma forma de interagir com PostgreSQL com tipagem, migrations e boa DX para solo dev.

## Decisão
Usar **Prisma** com PostgreSQL.

## Consequências
✓ Tipagem automática gerada do schema — zero tipos manuais de DB  
✓ Migrations com histórico e rollback  
✓ Prisma Studio para inspecionar dados em dev  
✓ DX superior para solo dev — menos SQL manual  
✗ Performance inferior ao Drizzle em queries muito complexas  
✗ Bundle size maior (gerador de cliente)  
✗ Algumas queries avançadas exigem `$queryRaw`  

## Alternativas consideradas
- **Drizzle ORM**: mais performático e type-safe, mas DX mais verbosa e migrations mais trabalhosas
- **TypeORM**: maduro mas API verbosa e decorators que complicam testes
- **Knex (query builder puro)**: flexível mas sem tipagem automática
